# 国网区域新型电力系统 · 碳感知计算与决策平台

> **项目定位**：区域新型电力系统碳感知计算、多源融合与因果归因智能中台（上海临港示范区）  
> **运行环境**：纯前端静态架构，零环境依赖，双击 `index.html` 即可直接在任何现代浏览器中完整运行。

## 二、平台五大业务模块与技术硬核体现

本系统严格剔除“原型演示”、“专利对应”等一切测试标签，让系统功能与页面数据直接证明技术实力：

1. **区域碳感知总览驾驶舱**：
   - **源-网-荷-储动态碳流拓扑图**：通过高帧率 HTML5 Canvas 渲染物理管网与发光流动粒子，粒子颜色严格随上游电源碳强度演化（红=煤电高碳，橙=燃气中碳，绿=风光零碳）。
   - **24小时分时动态碳因子曲线**：堆叠煤/气/风/光出力与动态碳因子（$EF_{动态}$），清晰呈现“午间光伏大发碳因子降至 398g/kWh，傍晚晚高峰火电顶峰升至 721g/kWh”的物理波动规律。
   - **CEMS 烟气连续监测通量**与火电机组热耗实时校验。

2. **多源数据接入与融合计算中心**：
   - **六大异构数据源实时接入看板**：涵盖 EMS（OPC UA）、SCADA（IEC 104）、CEMS（MQTT）、新能源群控、微气象预报、全国碳市场 CEA 行情。
   - **跨源多维特征关联发现网络**：基于 TransTab 语义编码与 HGSL 异质图结构自演化，展示系统自动识别的跨系统隐藏关联与 RotatE 复数空间置信度。
   - **时空多模态动态融合流**：对比融合前（散乱时延噪声）与融合后（状态空间平滑基准），并展示时空 MoE 专家门控网络的动态调度分配。

3. **全环节碳足迹知识图谱构建与核算**：
   - **交互式图谱浏览器**：涵盖物理设备、电网拓扑、用电终端、燃料本体、政策规程、碳市场等 18 类核心实体与 20 余条拓扑关系，支持拖拽、缩放与穿透式属性弹窗。
   - **图谱自动化构建管线回放**：一键回放“实体抽取 → 拓扑对齐 → 物理/业务双重约束校验（基尔霍夫碳流守恒）→ 全景固化”四步流程。
   - **企业穿透式用电碳足迹精准核算账单**：可任意选择化工、重工或智算中心，图谱即时高亮供电物理拓扑路径，输出电源分摊比例与区块链防伪存证凭证。

4. **因果图推理与归因系统**：
   - 提供**三大典型工业故障与极端场景**（盛夏持续高温负荷脉冲、近海骤然无风新能源跌落、火电机组燃料热值劣化）。
   - **动态因果路径游走推演**：逐步点亮因果链条，激活一阶软逻辑规则，定量输出 Top-K 关键驱动因子贡献度排行与自主生成的调控决策建议。

5. **技术底座与标准库**：
   - 权威内置中华人民共和国生态环境部 2024 年官方最新电力碳足迹因子规程与技术体系白皮书。

## 三、快速启动

1. 直接在 Windows 资源管理器中双击打开 `index.html`，系统将通过默认浏览器启动。
2. 或在当前目录下启动任意静态服务器（例如 VSCode Live Server，或命令行 `python -m http.server 8080` 后访问 `http://localhost:8080`）。
